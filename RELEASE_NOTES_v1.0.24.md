# EMX Desktop Flow v1.0.24

## Background thumbnail hotfix

- Checking for new background drops no longer destroys and recreates unchanged catalog cards, so already-loaded thumbnails remain visible.
- Installed video backgrounds now seek to a representative frame when their card loads instead of remaining on a black frame at time zero.
- Hover playback remains available for video previews.
- Preserves the restored temperature sensor host, Celsius/Fahrenheit selector, individual cursor selection, Color Studio quick save, navigation polish, and Capture Lab from v1.0.23.

The installer is covered by `SHA256SUMS.txt` and verified by Desktop Flow before installation. It is not Authenticode signed.
